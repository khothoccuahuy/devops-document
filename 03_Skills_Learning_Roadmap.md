## 3.1 Purpose

This section defines the skills expected at each level of the DevOps team and provides a structured learning path for career growth. Every engineer should use this as a self-assessment tool and career development guide.

---

## 3.2 Core Skill Domains

| Domain | Examples |
|---|---|
| **Cloud Platforms** | AWS, GCP, Azure |
| **Infrastructure as Code** | Terraform, Pulumi, Ansible |
| **Containerization** | Docker, Kubernetes, Helm |
| **CI/CD** | GitHub Actions, GitLab CI, Jenkins, ArgoCD |
| **Observability** | Prometheus, Grafana, Datadog, ELK Stack |
| **Scripting & Automation** | Bash, Python, Go |
| **Networking** | DNS, Load Balancers, VPNs, Service Mesh (Istio) |
| **Security** | SAST, DAST, Vault, IAM, RBAC |
| **Databases** | RDS, DynamoDB, Redis, backup strategies |
| **Soft Skills** | Communication, documentation, incident leadership |
